# Monitoring And Logging

## Observability Stack

- Prometheus for service metrics and scrape targets
- Grafana dashboards for congestion, API latency, and AI inference health
- Loki or ELK for structured application logs
- OpenTelemetry for traces across API, AI, cache, and notification flows

## Key Metrics

- Request latency by endpoint and tenant role
- WebSocket connection count and event throughput
- Redis hit ratio and queue lag
- Signal optimization execution time
- Emergency override count and duration
- AI model inference latency and confidence score drift
